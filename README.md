# DriveTrack Frontend 🚗📱

Interfaz multiplataforma para **DriveTrack**. Aplicación móvil construida con **Flutter** enfocada en la gestión inteligente de vehículos. Diseñada para una integración fluida con la [API de DriveTrack](https://github.com/DaniMancillaDev/DriverTrack).

## ✨ Experiencia de Usuario
DriveTrack ofrece una interfaz moderna y fluida con un enfoque en la interactividad y la experiencia de usuario:

- **Garaje Inteligente**: Visualización y gestión de flotas con estados dinámicos.
- **Bitácora de Mantenimiento**: Registro detallado de servicios con filtrado avanzado.
- **Service Map**: Mapa interactivo con localización de talleres y servicios cercanos.
- **Dashboard de Perfil**: Estadísticas de ahorro y personalización del ecosistema.
- **Notificaciones**: Alertas meteorológicas y recordatorios preventivos en tiempo real.

## 🏗️ Arquitectura
El proyecto sigue una estructura modular y escalable para Flutter:

- **Pages**: Pantallas completas diseñadas con una jerarquía clara.
- **Widgets**: Componentes de UI reutilizables y altamente personalizables.
- **Theme**: Sistema de diseño basado en Material 3 con soporte total para Dark Mode.
- **Layouts**: Estructuras responsivas adaptadas para diversas resoluciones.

## 🚀 Tecnologías
- **Flutter 3.x** - Framework multiplataforma de Google.
- **Dart** - Lenguaje de programación optimizado para UI.
- **Material 3** - Sistema de diseño moderno con efectos de glassmorphism.
- **Google Fonts (Inter)** - Tipografía premium para legibilidad superior.

## ⚙️ Instalación y Configuración Local

### 1. Requisitos Previos
- Instalar [Flutter SDK](https://docs.flutter.dev/get-started/install)
- Un editor (VS Code o Android Studio) con plugins de Flutter/Dart.

### 2. Clonar y Preparar el entorno
```bash
# Clona este repositorio
git clone https://github.com/DaniMancillaDev/DriverTrack_Frontend.git
cd DriverTrack_Frontend

# Obtén las dependencias
flutter pub get
```

### 3. Ejecutar la Aplicación
Asegúrate de tener un emulador encendido o un dispositivo conectado:
```bash
# Ejecutar en modo debug
flutter run
```
